# Design v1 (archive)

These are the v1 design documents as they stood at v0.2.2, when design v2 arrived.

- **Why they're kept:** they describe systems that are built and still in use (land, ship, submarine, aircraft and helicopter physics, damage, the Drafting Office, the Workshop, the ladder now called the Gauntlet). Code comments such as `design/05 §7.3` refer to **these files**.
- **Which document wins:** where the v2 documents (`design/01`–`10`) say something different, v2 wins. Where v2 says nothing, these rules stand.
- **Code comments:** when you edit a code file, point its comments at the v2 section if one exists, or at `design/v1/…`.
